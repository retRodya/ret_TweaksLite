# ret_TweaksLite — Vision

> Документ отвечает на вопросы «что это, для кого и чего в нём нет».
> Это не спецификация и не список задач: задачи живут в GitHub Issues.
> Меняется редко, и каждое изменение — осознанное решение.

## Одной фразой

Аддон для World of Warcraft Retail и Forever с небольшим набором твиков, которых
автору не хватает в игре: другие аддоны их либо не дают, либо прячут среди сотен
лишних опций.

## Для кого

- Для автора: только те твики, которыми он реально пользуется.
- Для игроков, которым Leatrix Plus и подобные аддоны кажутся избыточными.

## Главный сценарий

1. Игрок открывает окно аддона.
2. Выбирает вкладку категории слева.
3. Включает чекбокс модуля. Справа от названия появляется серая кнопка.
   Подсказка на ней: название модуля и «Type /reload to enable this module.»
4. Игрок нажимает Reload UI внизу окна или вводит `/reload`. Модуль запускается.
5. Если у модуля есть настройки, кнопка становится активной и открывает их.

## Принципы

- **Лёгкий.** Только нужные твики, и у каждого — минимум опций.
- **Изменения через `/reload`.** Модуль включается и выключается только при загрузке
  интерфейса. Модулю не нужно уметь «откатываться» на лету, поэтому его код
  проще и надёжнее.
- **Выключенный модуль ничего не стоит.** Не создаёт фреймы, не подписывается
  на события, не ставит хуки и не тратит CPU.
- **Игра возвращается как была.** Игровые настройки (CVar), которые менял модуль,
  восстанавливаются при его выключении — даже если клиент перед этим вылетел.
- **Выглядит как часть игры.** Окно из шаблонов Blizzard, родные шрифты
  и стили подсказок.
- **Один код для двух клиентов.** Одни и те же файлы работают в Retail и Forever.
- **Интерфейс аддона на английском.** Локализация — не раньше, чем аддон стабилен.

## Понятия

| Термин | Значение |
| --- | --- |
| **Module** | Один твик. В окне — чекбокс с названием, в коде — отдельный файл. |
| **Category** | Группа модулей. Вкладка в левой части окна. |
| **Config button** | Кнопка справа от названия модуля. Серая — модуль ждёт `/reload`. Активная — открывает настройки модуля. |
| **Pending** | Состояние модуля, когда чекбокс уже изменён, а `/reload` ещё не было. |

## Версия 0.1.0 — что входит

### Окно (ядро)

- Собственное окно аддона из шаблонов Blizzard.
- Вкладки категорий слева, модули выбранной категории справа.
- У модуля — чекбокс с названием и подсказка с описанием.
- Config button справа от названия:

  | Работает сейчас | Чекбокс | Кнопка | Подсказка |
  | --- | --- | --- | --- |
  | нет | выкл | нет | — |
  | нет | вкл | серая | название модуля, «Type /reload to enable this module.» |
  | да | выкл | серая | название модуля, «Type /reload to disable this module.» |
  | да | вкл | нет, если у модуля нет настроек | — |
  | да | вкл | активная, если настройки есть (после 0.1.0) | название модуля, «Click to open settings.» |

- Кнопка Reload UI внизу окна. Видна, пока есть изменения, которые ждут `/reload`.
- Включение и выключение модулей применяется после `/reload`.

### Управление

- Окно открывается командами `/rettl` и `/rettweakslite`, из Addon Compartment
  и со страницы аддона в Settings → AddOns.
- Настройки общие для всех персонажей аккаунта.

### Модули

**Tooltips**

- **Health bar above tooltip.** Полоса здоровья на подсказке юнита стоит
  над подсказкой, а не под ней. Это та же полоса Blizzard: модуль только
  переносит её и не читает здоровье. Без настроек.

## Версия 0.1.0 — что осознанно НЕ входит

- Страницы настроек модулей. Появятся вместе с первым модулем, которому
  они нужны.
- Включение и выключение модулей без `/reload`.
- Профили, импорт и экспорт настроек.
- Локализация.
- Кнопка у миникарты.
- Поиск по модулям.
- Совместимость с аддонами, которые сами двигают или прячут полосу здоровья
  подсказки (TipTac, ElvUI).
- Публикация на CurseForge — отдельная веха после 0.1.0.

## Когда 0.1.0 готова

- Работает в Retail и в Forever без ошибок Lua.
- Полоса здоровья стоит над подсказкой у игроков, NPC и питомцев, в том числе в бою.
- Включение и выключение модуля надёжно применяется после `/reload`.
- Кнопка и подсказка соответствуют состоянию модуля из таблицы выше.
- Выключенный модуль не даёт нагрузки на CPU.
- Проверено в игре по чек-листу.

## Знания из references

Находки из чужих аддонов в `references/` и из кода Blizzard. Берём идеи
и знания об API, не код.

### Leatrix Plus

- Хранит два состояния: с каким интерфейс загрузился и что сейчас отмечено
  в чекбоксах. Сравнивает их, чтобы понять, нужен ли `/reload`
  (`LeaPlusLC:ReloadCheck`, `LeaPlusLC:LockOption`).
- Кнопка-шестерёнка крепится справа от текста чекбокса
  (`SetPoint("LEFT", label, "RIGHT")`), текстура `Interface\WorldMap\Gear_64`.
  Серое состояние — `Disable()` и `SetAlpha(0.3)`.
- Выключенная кнопка по умолчанию не показывает подсказку. Нужен
  `SetMotionScriptsWhileDisabled(true)`.
- Своё окно плюс страница в Settings → AddOns
  (`Settings.RegisterCanvasLayoutCategory`), из которой открывается окно.
- Чего не повторять: весь аддон в одном файле на 18 000 строк, а модули,
  требующие `/reload`, перечислены вручную в одной функции. У нас модуль
  сам сообщает ядру о себе.

### Полоса здоровья подсказки

- В Retail это `GameTooltip.StatusBar` (глобальное имя `GameTooltipStatusBar`).
  Она описана в XML (`Blizzard_GameTooltip/Mainline/GameTooltip.xml`): высота 8,
  привязка `TOPLEFT` к `BOTTOMLEFT` подсказки (2, -1) и `TOPRIGHT`
  к `BOTTOMRIGHT` (-2, -1). Код Blizzard на Lua её не перепривязывает,
  а только показывает, прячет и обновляет значение. Значит, достаточно
  перепривязать её один раз при загрузке.
- В Midnight у полосы есть `GameTooltipUnitHealthBarSecureMixin`, а здоровье юнита
  бывает «секретным» значением, которое аддон не может прочитать. TipTac рисует
  свои полосы, но для секретного здоровья оставляет полосу Blizzard. Мы здоровье
  не читаем, поэтому эта проблема нас не касается.
- Проверить в игре: что XML полосы в Forever такой же; что полоса не уходит
  за верхний край экрана, когда подсказка у самого верха.
